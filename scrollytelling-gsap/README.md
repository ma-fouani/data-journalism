# Scrollytelling GSAP Project

This project is a scrollytelling webpage built using GSAP (GreenSock Animation Platform). It features smooth animations triggered by scrolling, creating an engaging storytelling experience.

## Project Structure

```
scrollytelling-gsap
├── src
│   ├── index.html          # Main HTML document
│   ├── styles
│   │   └── main.css       # Styles for the webpage
│   ├── scripts
│   │   ├── main.js        # Main JavaScript entry point
│   │   └── scroller.js    # Scroll event handling logic
│   ├── components
│   │   ├── section-hero.html  # Hero section HTML
│   │   └── section-story.html  # Story section HTML
│   └── data
│       └── content.json   # Content data in JSON format
├── package.json            # npm configuration file
├── vite.config.js          # Vite configuration file
├── .gitignore              # Git ignore file
└── README.md               # Project documentation
```

## Getting Started

To get started with this project, follow these steps:

1. **Clone the repository:**
   ```
   git clone <repository-url>
   cd scrollytelling-gsap
   ```

2. **Install dependencies:**
   ```
   npm install
   ```

3. **Run the development server:**
   ```
   npm run dev
   ```

4. **Open your browser:**
   Navigate to `http://localhost:3000` (or the port specified in your terminal) to view the scrollytelling webpage.

## Features

- Smooth scrolling animations using GSAP
- Modular HTML components for easy maintenance
- Responsive design for various screen sizes
